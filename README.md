# Aramielle App

A Flutter application prepared and configured for development.

## Project Structure

```text
lib/
├── main.dart             # App entry point
└── src/
    ├── app.dart          # MaterialApp configuration (Material 3 themes, routing)
    └── home/
        └── home_screen.dart # Home screen widget
test/
└── widget_test.dart      # Widget tests
```

## Getting Started

### Prerequisites

- Flutter SDK (3.x or higher)
- Dart SDK (3.x or higher)

### Commands

- **Fetch dependencies**: `flutter pub get`
- **Run project**: `flutter run`
- **Analyze code**: `flutter analyze`
- **Run tests**: `flutter test`
